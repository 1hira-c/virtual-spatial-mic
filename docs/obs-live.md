# Virtual Spatial Mic OBSプラグイン

OBSを終了してから、パッケージ内の `obs/vrc-binaural-studio` フォルダーを `C:\ProgramData\obs-studio\plugins` へ配置します。既存の同名フォルダーがある場合は先にバックアップしてください。

OBSを起動し、ソースの追加から「Virtual Spatial Mic（ライブ録音）」を選びます。マイク・使用チャンネル・音声の保存先を選んで入力を有効にします。

VRChatではモジュール入りアバターを使い、OSCをONにしてカメラを開きます。撮影レンズ本体を一度少し動かしてください。頭部・手首のOSC送信許可は不要です。

口元とカメラの取得状態・音声メーターを確認し、OBSで録画を開始します。停止するとVSMの保存も確定します。原音・位置データの保存は初期状態で有効です。音声保存先とOBS動画の保存先は別です。

ライブ入力は録画の合間も継続します。使い終わったらVSMの入力を無効にするかOBSを終了します。単体版の入力は同時に有効にしないでください。

VSMは音声ソースです。カメラ映像は別途追加します。未処理のマイク音を他のソースで重ねていないか、録画トラックの割り当ても確認してください。OBS版は取得時刻から300 ms後の音声出力を予定します。映像側の遅延は実際の録画で確認・調整してください。

「Virtual Spatial Mic（記録再生）」は保存済み音声を再生する別のソースです。ライブ録音には使いません。
