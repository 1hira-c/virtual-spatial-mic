# OBSで使う

VSMはOBSプラグインを使いません。単体版 `vsm.exe` が処理済みのステレオ音声をWindowsの出力デバイスへ再生し、OBSがその音をWindows標準の方法で取り込みます。OBSの録画開始・停止に合わせた保存は、OBS内蔵のWebSocketサーバー経由で連動します。

## 1. VSMの出力を用意する

1. `vsm.exe` でマイクと使用チャンネルを選び、**「入力を有効にする」** を押します。
2. **「モニター出力」** でOBSへ送る出力先を選び、**「モニター開始」** を押します。出力先は下の「2」で選ぶ方法に合わせます。
3. 出力ゲインで音量を調整します。VSMの出力は取得時刻から300 ms後に再生するよう予定されます。

モニターは入力を有効にしている間だけ動きます。入力を無効にしたり、アプリを再起動したりした後は、もう一度モニターを開始してください。

## 2. OBSで音声を取り込む

次のどちらかを選びます。

### A. アプリケーション音声キャプチャ（追加ソフト不要）

OBS 28以降・Windows 10 2004以降で使えます。

1. OBSの **「ソース」** 欄の **＋** から **「アプリケーション音声キャプチャ（BETA）」** を追加します。
2. **「ウィンドウ」** で `[vsm.exe]: Virtual Spatial Mic` を選びます。
3. VSMのモニター出力には、**普段聴いていない出力デバイス**（使っていないスピーカーやモニターのHDMI音声など）を選びます。

注意点：

- 取り込み対象は、そのデバイスではなく「VSMのアプリが再生する音すべて」です。VSMの録音ライブラリで試聴した音も取り込まれるので、OBSで録画中は試聴しないでください。
- Windowsの音量ミキサーでVSMをミュートすると、OBSに届く音も無音になります。
- モニター出力に自分のヘッドホンを選ぶと、300 ms遅れた自分の声が聞こえます。聴きながら収録したい場合は、OBSでこのソースの **「音声モニタリング」** を **「モニターと出力」** にしてください。
- VSMのウィンドウは最小化しても構いませんが、閉じると取り込みが止まります。

### B. 仮想オーディオケーブル（VB-CABLEなど）

聞かれていない出力デバイスがない場合や、Discordなど他のアプリにも送りたい場合に使います。仮想オーディオケーブルは各自で導入してください（例：VB-Audio社の [VB-CABLE](https://vb-audio.com/Cable/)。寄付制のソフトウェアです）。

1. Windowsのサウンド設定で、**「CABLE Input」** の既定の形式を **48000 Hz** にします。
2. VSMのモニター出力で **「CABLE Input」** を選びます。
3. OBSで **「音声入力キャプチャ」** を追加し、デバイスに **「CABLE Output」** を選びます。

### どちらの方法でも

- VSMが扱うのは音声だけです。映像ソースは別途追加してください。
- 同じマイクの未処理音を、別の音声入力キャプチャで重ねて録っていないか確認してください。
- 録画に使う音声トラックの割り当ても確認してください。

## 3. 録画開始・停止と保存を連動させる

OBSの録画に合わせて、VSMの保存（原音・位置データを含む）を自動で開始・停止できます。

1. OBSの **「ツール」→「WebSocketサーバー設定」** で **「WebSocketサーバーを有効にする」** をONにします。**「認証を有効にする」** のパスワードは **「接続情報を表示」** で確認できます。
2. VSMの **「OBS連携」** を開き、**「OBSの録画開始・停止に合わせて保存する」** をONにします。ホスト（通常は `127.0.0.1`）・ポート（初期値 `4455`）・パスワードを入力し、**「接続設定を保存」** を押します。
3. 状態が **「接続済み」** になったら、VSMで入力を有効にしてOBSの録画を開始します。

動作：

- 連携中はVSMの **「録音を開始」** ボタンは使えません。OBSの録画開始・停止に合わせて保存します。
- 入力を有効にした時点でOBSがすでに録画中なら、その録画に途中から参加して保存を始めます。
- OBSの録画の一時停止・再開は、記録にイベントとして残ります。
- 録画停止時は、OBSの動画ファイルのパスを記録に残します。
- OBSの終了や接続切れで録画の終了を確認できなくなった場合も、その時点で保存を終了します。OBSが起動し直すと自動で再接続します。
- OBSが録画を始めても、VSMの入力は自動では有効になりません。先に入力を有効にしておいてください。

パスワードはVSMの設定フォルダーの `obs-link.json` に保存されます（OBS自身の設定と同じく暗号化はしていません）。録音フォルダーの記録には含まれません。

## 4. 映像との同期

VSMの出力は、マイクで取得した時刻から300 ms後に再生されます。OBSでは音が映像より約300 ms遅れて届くので、VRChatの映像ソースに **「フィルタ」→「レンダリング遅延」** を追加し、約300 msから調整してください。仮想オーディオケーブルやOBS側の取り込みでも数十ms程度の遅れが加わることがあります。最終的な値は、手をたたく動作などを実際に録画して確認します。
