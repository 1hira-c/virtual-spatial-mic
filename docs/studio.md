# Virtual Spatial Mic

モジュールを導入したアバターでVRChatに入り、OSCをONにしてカメラを開きます。撮影レンズ本体を一度少し動かしてください。頭部・手首のOSC送信許可は不要です。

左のアイコンにマウスを重ねると画面名が表示されます。機器と保存先は左下の歯車から「設定」を開いて選びます。

1. `vsm.exe` を起動します。
2. 「設定」でマイク・使用チャンネル・モニター出力を選び、保存先を確認します。
3. 「音のみ」タブで「入力を有効にする」を押し、入力メーターと口元・カメラの取得状態を確認します。
4. 「モニター開始」を押し、出力ゲインで音量を調整します。
5. 「録音を開始」を押します。
6. 停止後、「ライブラリ」タブから処理済み音声または原音を聴けます。動画付きの録音は、そのまま動画を確認できます。

「音のみ」と「録画」は、マイク・ゲイン・出力などの設定を引き継ぐ収録モードの切り替えです。収録中・保存中は別モードへ切り替えられません。「ライブラリ」と「設定」へは収録中も移動でき、上部に収録状態・停止ボタン・「収録へ戻る」が表示されます。OBSに連動する収録はOBS側で停止します。画面を移っても入力・モニター・収録は止まりません。

録音中と停止直後の保存処理中はゲインを固定します。入力を有効にしただけの待機中は調整できます。マイク・使用チャンネル・保存先の変更には入力の無効化が必要です。位置データ待ちの間は処理済み音声が無音になります。

原音保存は初期状態で有効です。保存した原音と位置情報から再処理できます。録音名は日時で始まり、名前の右のペンから変更できます。録音の停止後も入力は待機します。使い終わったら入力を無効にするかアプリを閉じます。

## 単体で動画も録る（試作）

VRChatの4K映像で自動受信と1分録画、4K合成映像とテスト音で30分連続録画を確認しました。実VRChatでの長時間の映像・音声同期、色、状態変更をまたぐ収録は引き続き確認しています。

VRChatカメラのSpout出力をONにし、VSMの「録画」タブを開くと、カメラ映像へ自動で接続します。大きな映像は常時表示され、録画開始前にも確認できます。同じ画面の収録操作から入力・モニター・録画を切り替えます。

声と映像のタイミングを合わせる場合は、「設定」の「動画の音声タイミング」を調整します。マイナスで音声を早め、プラスで遅らせます（初期値0 ms、±2000 ms）。値は保存され、次の録画から適用されます。WAV・モニター音声と保存済みの動画は変わりません。音声を早める設定では、停止後にその分の音声末尾を待って保存します。

単体録画は「設定」の「OBS連携」をOFFにして使用します。「録画を開始」で映像と処理済みマイク音声を一緒に記録し、「録画を停止」でMP4（H.264 / AAC、30 fps）を保存します。OBSは不要です。ワールド音・システム音は今回の録画に含みません。

MP4に入る映像と音声は開始ボタンを押した時点からです。再処理用の原音・位置情報には、従来通り開始直前の分も残します。停止後は「ライブラリ」タブから「動画」「処理済み音声」「原音 (RAW)」を切り替えられます。動画付きの録音を選ぶと動画が表示され、選択だけでは再生を開始しません。再処理で更新されるのはWAVです。MP4の音声は録画時のまま残ります。

## OBSで録画する

OBSで映像と一緒に録る場合は「音のみ」タブを使い、モニター出力をOBSへ取り込み、「OBS連携」で録画開始・停止と保存を連動させます。手順は同梱の `OBS.md` を参照してください。

録音を選ぶと、プレイヤーもその録音へ切り替わります。動画なしの録音では処理済み／原音の選択を引き継ぎ、選んだ種類がなければ保存されている方を読み込みます。選択だけでは再生を開始しません。ライブラリを離れると試聴は一時停止し、選択と再生位置は保持します。「再処理」は折りたたみ式で、開閉状態を保持します。

## Windowsのネットワーク通信

音声・OSC・OSCQuery HTTPは、このPC内の `127.0.0.1` で扱います。VRChatの自動検出にはmDNSを使うため、サービス名とポートの広告はLANにも送信されます。Windowsでは自動検出の受信をOS標準のDNS-SDに任せ、VSMのmDNSソケットは広告の送信だけに使います。広告の送信元にはネットワークインターフェースのアドレスを使いますが、OSC・HTTPの受信先はlocalhostに限定します。ファイアウォールの許可ルールを自動で追加する処理もありません。
