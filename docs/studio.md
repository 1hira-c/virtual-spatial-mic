# Virtual Spatial Mic

モジュールを導入したアバターでVRChatに入り、OSCをONにしてカメラを開きます。撮影レンズ本体を一度少し動かしてください。頭部・手首のOSC送信許可は不要です。

1. `vsm.exe` を起動します。
2. 「音のみ」タブでマイクと使用チャンネルを選び、「入力を有効にする」を押します。
3. 入力メーターと口元・カメラの取得状態を確認します。
4. モニター出力にヘッドホンを選び、モニターを開始します。出力ゲインで音量を調整します。
5. 保存先設定を確認して録音を開始します。
6. 停止後、「ライブラリ」タブから処理済み音声または原音を聴けます。動画付きの録音は、そのまま動画を確認できます。

「音のみ」と「録画」は、マイク・ゲイン・出力などの設定を引き継ぐ収録モードの切り替えです。収録中・保存中は別モードへ切り替えられません。「ライブラリ」へは収録中も移動でき、上部に収録状態・停止ボタン・「収録へ戻る」が表示されます。OBSに連動する収録はOBS側で停止します。タブを移っても入力・モニター・収録は止まりません。

録音中と停止直後の保存処理中はゲインを固定します。入力を有効にしただけの待機中は調整できます。位置データ待ちの間は処理済み音声が無音になります。

原音保存は初期状態で有効です。保存した原音と位置情報から再処理できます。録音名は日時で始まり、名前の右のペンから変更できます。録音の停止後も入力は待機します。使い終わったら入力を無効にするかアプリを閉じます。

## 単体で動画も録る（試作）

Spoutのテスト映像で録画・再生を確認しています。VRChat実機での動画録画、映像との同期・色・長時間録画はまだ検証していません。

VRChatカメラのSpout出力をONにし、VSMの「録画」タブを開きます。「Spout映像」でカメラの映像を選び、一覧にない場合は右の更新ボタンを押してください。「映像プレビュー」を開くと、録画開始前にも映像を確認できます。

単体録画は「OBS連携」をOFFにして使用します。「録画を開始」で映像と処理済みマイク音声を一緒に記録し、「録画を停止」でMP4（H.264 / AAC、30 fps）を保存します。OBSは不要です。ワールド音・システム音は今回の録画に含みません。動画設定は音声入力が有効な待機中も変更できますが、録音・録画中と保存処理中は固定します。

MP4に入る映像と音声は開始ボタンを押した時点からです。再処理用の原音・位置情報には、従来通り開始直前の分も残します。停止後は「ライブラリ」タブから「動画」「処理済み音声」「原音 (RAW)」を切り替えられます。動画付きの録音を選ぶと動画が表示され、選択だけでは再生を開始しません。再処理で更新されるのはWAVです。MP4の音声は録画時のまま残ります。

## OBSで録画する

OBSで映像と一緒に録る場合は「音のみ」タブを使い、モニター出力をOBSへ取り込み、「OBS連携」で録画開始・停止と保存を連動させます。手順は同梱の `OBS.md` を参照してください。

録音を選ぶと、プレイヤーもその録音へ切り替わります。動画なしの録音では処理済み／原音の選択を引き継ぎ、選んだ種類がなければ保存されている方を読み込みます。選択だけでは再生を開始しません。ライブラリを離れると試聴は一時停止し、選択と再生位置は保持します。「再処理」は保存先設定と同じ折りたたみ式で、開閉状態を保持します。

## Windowsのネットワーク通信

音声・OSC・OSCQuery HTTPは、このPC内の `127.0.0.1` で扱います。VRChatの自動検出にはmDNSを使うため、サービス名とポートの広告はLANにも送信されます。Windowsでは自動検出の受信をOS標準のDNS-SDに任せ、VSMのmDNSソケットは広告の送信だけに使います。広告の送信元にはネットワークインターフェースのアドレスを使いますが、OSC・HTTPの受信先はlocalhostに限定します。ファイアウォールの許可ルールを自動で追加する処理もありません。
