# 導入から最初の録音まで

口追跡モジュール（以下、モジュール）を導入したアバターを使い、マイクの音を撮影カメラに合わせて立体音声にする手順です。Windows x64・VRChatのVR／デスクトップモードを対象とします。

VSM 0.1.0と口追跡モジュール0.2.0-previewの手順です。自分でビルドする場合は[開発者向けドキュメント](development.md)を参照してください。

## どちらで録るか選ぶ

| 目的 | 使用するもの |
|---|---|
| まず音だけ録って聴きたい | 単体アプリ |
| 映像と一緒にOBSで録画したい | OBSプラグイン |

モジュールとVRChatの準備は共通です。その後、使う方の手順へ進んでください。OBSプラグインで録音するために単体版を起動する必要はありません。

## 1. アバターへモジュールを追加する

Unityで編集できるアバターのプロジェクトに、VRChat Avatars SDKとModular Avatarを導入しておきます。アバターのプロジェクトは先にバックアップしてください。

同梱モジュールは `VSM_Mouth_Tracking_0.2.0-preview.unitypackage` です。

1. 使用するアバターのUnityプロジェクトとシーンを開きます。上部メニューの **Assets → Import Package → Custom Package…** からモジュールの `.unitypackage` を選び、内容をインポートします。
2. Project内の **Assets → VirtualSpatialMic → Modules** を開き、**VSM_Mouth_Tracking**（prefab）をHierarchyのアバター名へドラッグします。アバター直下にモジュールが1個ある状態にします。
3. Hierarchyで追加したモジュールを展開し、**Mouth → Attachment → point** を選びます。初期位置はHeadボーンの中心です。
4. Sceneの移動ツール（**W**）で、選んだ `point` の位置を口の中央に合わせます。正面から左右・高さ、横から前後を確認します。細かく合わせる場合はInspectorの **Transform → Position** を使います。`Rotation` と `Scale`、親の `Attachment` の設定はそのままにします。
5. シーンを保存し、そのアバターをVRChatへアップロードします。
6. VRChatで、モジュールを追加してアップロードしたアバターへ着替えます。

口元調整はアバターごとの初回設定です。録音するたびに位置を合わせ直す必要はありません。調整はHierarchy上のアバターに追加したモジュールで行います。Projectのprefabを直接開いて編集する必要はありません。なお、このモジュールは頭に固定した発音位置を追跡するもので、表情による唇の変形を追うものではありません。

元のFX・Expression Parameters・ボーンを直接書き換える手順は不要です。モジュールはModular Avatarでビルド時に統合します。[モジュールの導入手順](../integrations/unity/README.md)も参照できます。

## 2. VRChatを準備する

1. VRChatに入り、モジュール入りアバターを使用します。VR／デスクトップのどちらでも使えます。
2. アクションメニューの `Options → OSC → Enabled` をONにします。
3. カメラを開き、撮影レンズ本体を一度少し動かします。

モジュールを使う収録では **「OSC経由で頭部と手首のトラッキングデータの送信を許可」** は不要です。口元はモジュールから取得します。OSC全体の有効化とは別の設定なので、OSCはONにしてください。

Local固定・World固定では、手元のカメラUIと撮影レンズ本体が別の場所にあります。位置が届かないときは、撮影レンズ本体を動かしてください。モジュールを使う収録では、開始前にカメラを口元へ寄せる校正は不要です。

## 3-A. 単体版で録音する

### 起動して入力を確認する

1. パッケージを展開し、`standalone` フォルダーの `vsm.exe` を起動します。`phonon.dll` は同じフォルダーに置いたままにします。
2. 画面上部の **「マイク入力」** で使用する機器を選びます。
3. **「使用チャンネル」** を選びます。モノラル入力は **「1（左 / モノラル）」**、2チャンネル機器の右側を使う場合は **「2（右）」** です。
4. **「入力を有効にする」** を押し、話したときに入力メーターが動くか確認します。
5. カメラと口元が取得できると **「準備完了」** になり、出力のL/Rメーターも動きます。

**「位置データ待ち」** の間は、原音の入力があっても処理後の出力は無音になります。メーターの下の説明を確認してください。

### 聴こえ方と保存先を確認する

1. 区切り線の下の **「モニター出力」** でヘッドホンを選び、**「モニター開始」** を押します。
2. **「出力ゲイン」** を調整し、聴こえ方とL/Rメーターを確認します。入力が有効な待機中も調整できます。録音中と停止直後の保存処理中は固定されます。
3. さらに下の **「保存先設定」** を開き、保存フォルダーを確認します。変更する場合は入力を無効にして **「保存先変更」** を使います。
4. 後から調整し直す場合は、**「再処理用の生データを保存する」** をONのままにします。

### 録って聴く

1. 入力ボタンの隣の **「録音を開始」** を押し、話しながら頭やカメラを少し動かします。
2. **「録音を停止」** を押します。
3. 下の **「録音ライブラリ」** で録音を選び、**「処理済み音声」** を押します。**「原音 (RAW)」** で元の音声も確認できます。
4. 必要なら、録音名の右にあるペンから名前を編集します。Enterまたはチェックで保存、Escまたは×でキャンセルします。

入力は録音停止後も待機します。使い終わったら **「入力を無効にする」** を押すか、単体版を閉じます。

## 3-B. OBSで録画する

### プラグインを配置する

1. OBSを終了します。
2. パッケージ内の `obs/vrc-binaural-studio` フォルダーを、`C:\ProgramData\obs-studio\plugins` の中へ配置します。更新時は、既存の同名フォルダーを先にバックアップします。
3. 配置後に次のファイルがあることを確認します。`data` 内の同梱資料・ライセンスも一緒に置きます。

```text
C:\ProgramData\obs-studio\plugins\vrc-binaural-studio\
  bin\64bit\vrc-binaural-studio.dll
  bin\64bit\phonon.dll
  data\
```

この配置先へのコピーでは、Windowsから管理者権限を求められる場合があります。配置後、OBSを通常どおり起動します。この手順はWindows版OBS 32.2.2を対象とします。

### ライブ録音ソースを追加する

1. 録画に使うシーンを選び、**「ソース」** 欄の **＋** を押します。
2. **「Virtual Spatial Mic（ライブ録音）」** を選び、**「新しいソースを作成」** を押します。ソース名を指定して追加すると、プロパティが開きます。
3. **「マイク」** と **「使用チャンネル」** を選びます。
4. **「音声・動きの保存先」** の **「参照」** で保存フォルダーを選びます。これはOBS動画の保存先とは別です。
5. **「原音・位置データを保存（後から再調整するため）」** は、後から再処理する場合はONにしておきます。
6. **「マイク入力・モニターを有効にする」** をONにします。設定変更で入力が再起動する場合があるため、ここまでを録画開始前に済ませます。
7. 上部の状態を確認します。カメラ待ちならVRChatの撮影レンズを少し動かし、口元待ちならモジュール入りアバターか確認します。

音量は、現行OBSプロパティでは **「入力レベル (dB)」** と表示されています。初期値は−18 dBです。まず初期値で確認してから調整してください。口元のXYZをOBSに入力する欄はありません。

**「Virtual Spatial Mic（記録再生）」** は、保存済みの録音を再生する別のソースです。最初のライブ収録では **「ライブ録音」** を選んでください。ソースに自分で付けた名前が表示される場合もあります。

### 映像・音声を確認して録画する

1. OBSへ撮影したい映像ソースを追加します。VSMが追加するのは音声ソースです。VRChatカメラをSpoutで取り込む場合、Spout用のOBSプラグインは別途必要です。
2. VSMのソースをミュート解除し、話したときに音声ミキサーのメーターが動くことを確認します。同じマイクの未処理音を別ソースでも重ねて録っていないか確認します。
3. 自分でも聴く場合は、音声ミキサー下部の歯車から **「オーディオの詳細プロパティ」** を開き、VSMの **「音声モニタリング」** を **「モニタリング有効」** にします。録画に使うトラックも確認します。
4. OBSの **「録画開始」** を押します。VSM側の保存も連動して始まります。
5. **「録画停止」** を押します。音声の保存が終わったら、VSMソースのプロパティにある **「前回の処理音声を聴く」** から試聴できます。

OBS 32.2.2のモニター選択肢は **「モニターオフ」** と **「モニタリング有効」** です。OBSの版によって表示が違う場合があります。モニター設定だけで録画先トラックの選択が済んだ扱いにはしません。

続けて撮る場合は、再びOBSの録画開始を押します。使い終わったらVSMの **「マイク入力・モニターを有効にする」** をOFFにするか、OBSを終了します。OBSでライブ録音している間は、単体版側の入力を無効にしておきます。

## 4. 保存先を開く・後から調整する

録音フォルダーの初期名は単体版・OBS共通で **録音開始日時 `yyyymmdd-hhMMss`** です。同名が存在する場合は上書きせずエラーになります。1秒以上あけて開始し直してください。既存の長い名前の録音もそのまま開けます。

| ファイル・操作 | 内容 |
|---|---|
| `live-output.wav` | 収録時の処理済みステレオ音声 |
| `raw/microphone.wav` | 生データ保存ONの場合のマイク原音 |
| 単体版「フォルダーを開く」 | 設定中の録音保存先を開く |
| 単体版の録音詳細にある外向き矢印 | 選択した録音のフォルダーを開く |
| OBS「前回の保存フォルダーを開く」 | 直前の録音のフォルダーを開く |

単体版の **「別の録音を開く」** から、OBSで保存した録音も選べます。生データを保存していれば、再処理の音量・位置の取得方法を選び、**「原音から再処理」** を押して作り直せます。元の音声は残ります。

音声ファイルには録音開始前の約10秒と停止後の短い余白が含まれるため、OBS動画とWAVをそのまま先頭合わせしても一致しません。最初はOBSが作った動画で映像と音の対応を確認してください。精密な同期調整と長時間安定性の検証は継続中です。

## 困ったとき

| 状態 | 最初に確認すること |
|---|---|
| 単体版の入力メーターが動かない | マイク機器・使用チャンネル・マイクの電源やミュート |
| 入力は動くが出力が無音 | 状態の説明、モジュール入りアバター、OSC、撮影レンズ本体の初回更新 |
| OBSの追加一覧にVSMがない | OBSを終了してからプラグイン配置と2つのDLLを確認し、再起動 |
| OBSのメーターは動くが録画が無音 | ソースのミュートと、録画に使う音声トラック |
| 保存先・容量のエラー | 表示された保存先と空き容量。保存開始には1 GiB以上が必要 |
| 名前を変更できない | 録音の保存や再処理の終了、重複名、使用できない文字 |

詳しい動作と制限は[単体版](studio.md)、[OBSライブ録音](obs-live.md)を参照してください。
