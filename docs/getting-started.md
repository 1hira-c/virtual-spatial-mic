# 導入から最初の録音まで

口追跡モジュール（以下、モジュール）を導入したアバターを使い、マイクの音を撮影カメラに合わせて立体音声にする手順です。Windows x64・VRChatのVR／デスクトップモードを対象とします。

VSM 0.2.0と口追跡モジュール0.2.0-previewの手順です。自分でビルドする場合は[開発者向けドキュメント](development.md)を参照してください。

## どちらで録るか選ぶ

| 目的 | 手順 |
|---|---|
| まず音だけ録って聴きたい | 単体アプリ（3-A） |
| VRChatカメラの映像と一緒に単体で録りたい | 単体アプリの動画録画（3-A、試作機能） |
| 映像と一緒にOBSで録画したい | 単体アプリ＋OBS（3-A の後に 3-B） |

いずれも単体アプリ `vsm.exe` を使います。VSM用のOBSプラグインは不要です。モジュールとVRChatの準備は共通です。単体動画録画にはOBS・FFmpeg・Spout SDKのDLLは必要ありません。

単体動画録画は新しい試作機能です。VRChat実機での録画はまだ検証していません。映像との同期・色・長時間録画の確認は継続中です。

## 1. アバターへモジュールを追加する

Unityで編集できるアバターのプロジェクトに、VRChat Avatars SDKとModular Avatarを導入しておきます。アバターのプロジェクトは先にバックアップしてください。

同梱モジュールは `VSM_Mouth_Tracking_0.2.0-preview.unitypackage` です。

1. 使用するアバターのUnityプロジェクトとシーンを開きます。上部メニューの **Assets → Import Package → Custom Package…** からモジュールの `.unitypackage` を選び、内容をインポートします。
2. Project内の **Assets → VirtualSpatialMic → Modules** を開き、**VSM_Mouth_Tracking**（prefab）をHierarchyのアバター名へドラッグします。アバター直下にモジュールが1個ある状態にします。
3. Hierarchyで追加したモジュールを展開し、**Mouth → Attachment → point** を選びます。初期位置はHeadボーンの中心です。
4. Sceneの移動ツール（**W**）で、選んだ `point` の位置を口の中央に合わせます。正面から左右・高さ、横から前後を確認します。細かく合わせる場合はInspectorの **Transform → Position** を使います。`Rotation` と `Scale`、親の `Attachment` の設定はそのままにします。
5. シーンを保存し、そのアバターをVRChatへアップロードします。
6. VRChatで、モジュールを追加してアップロードしたアバターへ着替えます。

口元調整はアバターごとの初回設定です。録音するたびに位置を合わせ直す必要はありません。調整はHierarchy上のアバターに追加したモジュールで行います。Projectのprefabを直接開いて編集する必要はありません。なお、このモジュールは頭に固定した発音位置を追跡するもので、表情による唇の変形を追うものではありません。

元のFX・Expression Parameters・ボーンを直接書き換える手順は不要です。モジュールはModular Avatarでビルド時に統合します。[モジュールの導入手順](../integrations/unity/README.md)も参照できます。

## 2. VRChatを準備する

1. VRChatに入り、モジュール入りアバターを使用します。VR／デスクトップのどちらでも使えます。
2. アクションメニューの `Options → OSC → Enabled` をONにします。
3. カメラを開き、撮影レンズ本体を一度少し動かします。

モジュールを使う収録では **「OSC経由で頭部と手首のトラッキングデータの送信を許可」** は不要です。口元はモジュールから取得します。OSC全体の有効化とは別の設定なので、OSCはONにしてください。

Local固定・World固定では、手元のカメラUIと撮影レンズ本体が別の場所にあります。位置が届かないときは、撮影レンズ本体を動かしてください。モジュールを使う収録では、開始前にカメラを口元へ寄せる校正は不要です。

## 3-A. 単体版で録音・録画する

**「音のみ」** と **「録画」** は、マイク・ゲイン・出力などの設定を引き継いで切り替えます。収録中・保存中は別の収録モードへ切り替えられませんが、**「ライブラリ」** へ移動して状態を確認したり停止したりできます。タブを移っても入力・モニター・収録は続きます。

### 起動して入力を確認する

1. パッケージを展開し、`Virtual Spatial Mic` フォルダーの `vsm.exe` を起動します。
2. **「音のみ」** タブの **「マイク入力」** で使用する機器を選びます。
3. **「使用チャンネル」** を選びます。モノラル入力は **「1（左 / モノラル）」**、2チャンネル機器の右側を使う場合は **「2（右）」** です。
4. **「入力を有効にする」** を押し、話したときに入力メーターが動くか確認します。
5. カメラと口元が取得できると **「準備完了」** になり、出力のL/Rメーターも動きます。

**「位置データ待ち」** の間は、原音の入力があっても処理後の出力は無音になります。メーターの下の説明を確認してください。

### 聴こえ方と保存先を確認する

1. 区切り線の下の **「モニター出力」** でヘッドホンを選び、**「モニター開始」** を押します。
2. **「出力ゲイン」** を調整し、聴こえ方とL/Rメーターを確認します。入力が有効な待機中も調整できます。録音中と停止直後の保存処理中は固定されます。
3. さらに下の **「保存先設定」** を開き、保存フォルダーを確認します。変更する場合は入力を無効にして **「保存先変更」** を使います。
4. 後から調整し直す場合は、**「再処理用の生データを保存する」** をONのままにします。

### 単体で動画も録る場合

1. VRChatカメラの設定でSpout出力をONにし、カメラを開いた状態にします。
2. VSMの **「録画」** タブを開き、**「Spout映像」** で映像の送信者を選びます。通常はVRChatの送信者を選びます。
3. **「映像プレビュー」** を開き、意図した映像が届いているか確認します。動画の設定は入力が有効な待機中も変更でき、収録中と保存処理中は固定されます。
4. **「OBS連携」** をOFFにし、入力と位置データが準備できたら、**「録画を開始」** を押します。
5. **「録画を停止」** を押し、保存が完了するまで待ちます。
6. **「ライブラリ」** タブで保存した録音を選び、**「動画」** からMP4を再生します。

動画は30 fpsで保存します。音声はVSMで処理したマイクのステレオ音声だけです。VRChatのワールド音・他の人の声・Windowsのシステム音は入りません。これらも収録する場合はOBSで録画してください。

MP4には録画開始前のプリロールを含めません。別途保存するWAVのプリロールは従来どおり残ります。

### 音だけ録って聴く

1. **「音のみ」** タブで、入力ボタンの隣の **「録音を開始」** を押します。話しながら頭やカメラを少し動かします。
2. **「録音を停止」** を押します。
3. **「ライブラリ」** タブで録音を選ぶと、再生する音声も切り替わります。**「処理済み音声」** と **「原音 (RAW)」** を切り替えて聴けます。
4. 必要なら、録音名の右にあるペンから名前を編集します。Enterまたはチェックで保存、Escまたは×でキャンセルします。

**「収録へ戻る」** で収録タブに戻れます。ライブラリを離れると試聴は一時停止し、選択した録音と再生位置は保持します。入力は録音停止後も待機します。使い終わったら **「入力を無効にする」** を押すか、単体版を閉じます。

## 3-B. OBSで録画する

3-Aの「起動して入力を確認する」まで済ませ、VSMは **「音のみ」** タブで使います。詳しい説明は[OBSで使う](obs-live.md)を参照してください。

### 音声をOBSへ取り込む

1. VSMの **「モニター出力」** で、OBSへ送る出力先を選んで **「モニター開始」** を押します。
   - **アプリケーション音声キャプチャ**を使う場合：普段聴いていない出力デバイスを選びます。
   - **仮想オーディオケーブル**（VB-CABLEなど）を使う場合：「CABLE Input」を選びます。
2. OBSの **「ソース」** 欄の **＋** から音声ソースを追加します。
   - アプリケーション音声キャプチャ：**「アプリケーション音声キャプチャ（BETA）」** を追加し、ウィンドウで `[vsm.exe]: Virtual Spatial Mic` を選びます。
   - 仮想オーディオケーブル：**「音声入力キャプチャ」** を追加し、「CABLE Output」を選びます。
3. 話したときにOBSの音声ミキサーのメーターが動くことを確認します。同じマイクの未処理音を別ソースで重ねて録っていないか、録画に使う音声トラックも確認します。
4. 撮影したい映像ソースを追加します。VRChatカメラをSpoutで取り込む場合、Spout用のOBSプラグインは別途必要です。

### 録画開始・停止と保存を連動させる

1. OBSの **「ツール」→「WebSocketサーバー設定」** で、WebSocketサーバーを有効にします。パスワードは **「接続情報を表示」** で確認できます。
2. VSMの **「OBS連携」** を開き、**「OBSの録画開始・停止に合わせて保存する」** をONにします。パスワードを入力して **「接続設定を保存」** を押し、状態が **「接続済み」** になることを確認します。
3. VSMの入力が有効な状態で、OBSの **「録画開始」** を押します。VSM側の保存も連動して始まります。
4. **「録画停止」** を押すと、VSM側の保存も終わります。VSMの **「ライブラリ」** タブから処理済み音声を試聴できます。ただし、アプリケーション音声キャプチャを使っている場合は、OBSで録画中に試聴しないでください（試聴音もOBSに入ります）。

連携中はVSMの録音ボタンは使えません。続けて撮る場合は、再びOBSの録画開始を押します。VSMの音声はOBSの映像より約300 ms遅れて届くため、映像ソースの **「レンダリング遅延」** フィルターで合わせてください。

## 4. 保存先を開く・後から調整する

録音フォルダーの初期名は **録音開始日時 `yyyymmdd-hhMMss`** です。同名が存在する場合は上書きせずエラーになります。1秒以上あけて開始し直してください。既存の長い名前の録音もそのまま開けます。

| ファイル・操作 | 内容 |
|---|---|
| `live-output.wav` | 収録時の処理済みステレオ音声 |
| `video.mp4` | 単体の動画録画で保存したSpout映像と処理済みマイク音声 |
| `raw/microphone.wav` | 生データ保存ONの場合のマイク原音 |
| 単体版「フォルダーを開く」 | 設定中の録音保存先を開く |
| 単体版の録音詳細にある外向き矢印 | 選択した録音のフォルダーを開く |

単体版の **「別の録音を開く」** から、別の場所にある録音（0.1.0のOBSプラグインで保存した録音を含む）も選べます。生データを保存していれば、再処理の音量・位置の取得方法を選び、**「原音から再処理」** を押して作り直せます。元の音声は残ります。

音声単体のWAVには録音開始前のプリロールと停止後の短い余白が含まれます。単体版の `video.mp4` は開始ボタンを押した時点から収録するため、MP4とWAVをそのまま先頭合わせしても一致しません。OBSの動画とWAVを使う場合も同様です。映像と音の対応は、まずMP4動画そのものを再生して確認してください。精密な同期調整と長時間安定性の検証は継続中です。再処理は音声を作り直す機能で、MP4の音声を置き換えるものではありません。

## 困ったとき

| 状態 | 最初に確認すること |
|---|---|
| 単体版の入力メーターが動かない | マイク機器・使用チャンネル・マイクの電源やミュート |
| 入力は動くが出力が無音 | 状態の説明、モジュール入りアバター、OSC、撮影レンズ本体の初回更新 |
| Spoutの映像送信者が見つからない | VRChatカメラのSpout出力がONか、カメラが開いているか |
| 単体動画の録画を開始できない | 映像送信者の選択、入力と位置データの準備、表示されたエラー |
| OBSのメーターが動かない | VSMのモニターが「出力中」か、OBSのソースで選んだウィンドウ・デバイス、Windowsの音量ミキサーでVSMがミュートされていないか |
| OBS連携が「接続済み」にならない | OBSのWebSocketサーバーが有効か、ポートとパスワード |
| OBSのメーターは動くが録画が無音 | ソースのミュートと、録画に使う音声トラック |
| 保存先・容量のエラー | 表示された保存先と空き容量。保存開始には1 GiB以上が必要 |
| 名前を変更できない | 録音の保存や再処理の終了、重複名、使用できない文字 |

詳しい動作と制限は[単体版](studio.md)、[OBSで使う](obs-live.md)を参照してください。
