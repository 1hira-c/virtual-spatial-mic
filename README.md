# Virtual Spatial Mic

**Virtual Spatial Mic (VSM)** は、外部マイクの音をVRChat内のアバターの口元に配置し、撮影カメラの位置で収音したような立体音声を生成する非公式ツールです。

単体アプリで音を録るほか、処理済みの音声をOBSへリアルタイムに渡せます。原音と位置情報を保存して後から処理し直すこともできます。

VSM 0.2.0です。Windows x64・VRChat（VR／デスクトップモード）・口追跡モジュールを導入したアバターを対象としています。モジュールは独立して版を管理し、0.2.0-previewとの組み合わせで動作確認しています。0.1.0のOBSプラグインは廃止しました。[変更履歴と既知の問題](CHANGELOG.md)を参照してください。
## 使い方

1. アバターに口追跡モジュール（以下、モジュール）を追加します。
2. VRChatでそのアバターを使い、OSCをONにしてカメラを開きます。
3. 単体版でマイクを選び、追跡状態と音声を確認します。
4. 録音を開始します。OBSと一緒に使う場合は、単体版の出力をOBSの音声ソースで取り込み、OBSの録画開始・停止に音声保存を連動させます。

[導入から最初の録音まで](docs/getting-started.md) / [OBSで使う](docs/obs-live.md) / [モジュールの導入](integrations/unity/README.md) / [ソースからビルドする](docs/development.md)

モジュールはModular Avatarで非破壊に追加できます。同期パラメーターの消費は0 bitです。口元の位置合わせはアバターへの導入時に一度行います。録音ごとにカメラを口元へ寄せる校正は不要です。

## VRChatの「Audio from Camera」との違い

VRChat内のワールド音や他の人の声をカメラ位置から聴く用途には、標準のAudio from Cameraが使えます。VSMが扱うのは、外部マイクなどから入ってくる音です。

OBSだけでは分からないアバターの口元とカメラの位置関係を使い、演者の声を空間化します。VSMはVRChat内の音を録音する機能や、Spout映像の取り込み機能を提供しません。

## 保存と再処理

原音保存は初期状態で有効です。原音・位置・時刻情報を残すことで、VRChatを終了した後にも再処理できます。元の音声は上書きしません。再処理は、録画時の出力とのサンプル単位の一致を保証するものではありません。

## 必要なものと制限

- Windows x64、音声入力、ヘッドホンまたはイヤホン
- VRChatと、モジュールを導入したアバター
- 映像と一緒に録る場合はOBS Studio 28以降（プラグインは不要）
- 単体版の実行にはWebView2 Runtime

初版は1音源・1カメラを対象とします。Linuxは対応対象外です。デスクトップモードでも実機動作を確認しており、カメラを使った上半身トラッキングとの併用も利用者による動作確認があります。近接効果の専用処理は未実装です。長時間の安定性、映像との同期、状態変更をまたぐ追従は引き続き検証しています。

処理済み音声は取得時刻から300 ms後に出力するよう予定します。OBSで映像と合わせる場合は、映像側の遅延を収録環境で調整してください。

Windowsでは入力を有効にした際、ファイアウォールの通信許可ダイアログが表示される場合があります。音声・位置データの受信とOSCQueryのHTTP受付はlocalhostですが、サービス発見用のmDNS広告はネットワークインターフェースから送信します。この表示の解消は未完了です。
